# cattle-health-rag-chatbot
Hybrid RAG-based AI chatbot for cattle health and veterinary information
## Experimental Files

The following files are retained for experimentation, testing, and development purposes only. They are not considered the primary or stable implementations of the chatbot.

- `rag_backup.py` – Backup version of the RAG pipeline, retained for reference and experimentation.
- `retrieval_backup.py` – Backup version of the hybrid retrieval implementation.
- `rag_optimized.py` – Experimental optimized version of the RAG pipeline, currently retained for performance testing and comparison.

**Note:** The primary implementations are `rag.py` and `retrieval.py`. Use these files when running the current chatbot.
